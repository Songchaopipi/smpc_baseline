01 · 全景一条主式，八个层级

先看结论。整个语料里 60 篇论文，剥掉各自的应用背景和工程技巧，剩下的数学内核是同一条更新式：

qm+1 = ProjΠ [ ∑i=1N wi · δUi ] ,    wi ∝ ρ(Ui) · exp( −J(Ui)/λ ) / qm(Ui) 主式 · 一次采样 MPC 迭代的全部内容

读法只有三个动作：采一批（从当前 qm）→ 打分（用代价 J 和温度 λ 重加权）→ 投回去（把带权经验测度投影回某个可采样族 Π）。第 m+1 轮重复。滚动 MPC 则是把这一坨塞进"执行首动作、窗口前移"的外壳里。

目标分布没有单独出现，因为它是被"打分"这一步隐式定义的：

p*(U) ∝ ρ(U) · exp( −J(U)/λ ) 目标 · 代价的 Gibbs 变换（也叫指数倾斜、softmin、玻尔兹曼分布）

于是"采样 MPC 怎么工作"可以浓缩成一句：你不知道 p* 怎么采样，但你会算 p* 的未归一化密度（因为有 J 和模型），于是用 qm 去提样本、用密度比去修正、再把结果压回 q 所在的族。这就是重要性采样 + 变分投影。剩下的全部是细节。

T0 · 数学底座只学后面真正用得到的四件事

采样 MPC 用到的数学，说到底是四样东西：期望、KL 的两个方向、一个自由能恒等式、重要性采样。其余都是这四样的组合。这一层不要跳，尤其是 KL 的方向——整个多模态文献（B 文件夹里 8 篇）存在的唯一理由，就是前向 KL 和反向 KL 会给出完全不同的投影结果。

0.1三种基本操作

任何采样方法都在做这三件事的某种组合：

操作记号在采样 MPC 里的角色
采样U1,…,UN ~ qm从当前提议分布抽一批候选轨迹
求期望Eq[ f(U) ] = ∫ f(U) q(U) dU估计"下一轮的中心应该在哪"
拟合qm+1 = argminq∈Π D( p* ‖ q )把带权样本压回可采样的族

"拟合"这一步是全体方法的分水岭：用哪个散度 D、投影到哪个族 Π，决定了你不会踩均值陷阱、能不能处理约束、要多少样本。这也是为什么下面要花整整一节讲 KL 的方向。

0.2KL 的两个方向：全篇最关键的单一事实

DKL(P‖Q) = EP[ log P(U) − log Q(U) ] = ∫ P log(P/Q) KL 不是距离：DKL(P‖Q) ≠ DKL(Q‖P)，而且两者会选出完全不同的 Q

把 P 看成固定的目标 p*，Q 看成你受限的族（比如单高斯）。两个方向各有一个别名，记住别名比记公式有用：

方向别名行为实际后果
前向 DKL(p*‖q) 矩投影 / 质量覆盖
moment projection		 P 有质量的地方 Q 必须有质量（否则 log Q → −∞，罚无穷大）。零回避。 双峰目标 + 单高斯族 ⇒ 高斯被拉宽去盖住两个峰，均值落在两峰之间。这就是均值陷阱。
反向 DKL(q‖p*) 信息投影 / 模式寻求
information projection		 Q 有质量的地方 P 必须有质量（否则 log q/p* → +∞）。零强制。 单高斯会挑一个峰贴上去，忽略另一个。想要多样性就必须显式加机制（粒子、混合、传输）。
一句话记住

前向 KL 求平均，反向 KL 挑一个。MPPI 的更新式本质上是前向 KL 的矩匹配，所以它天生会把两条低代价路线平均成一条中间的烂路线；这不是实现 bug，是散度选错了。B 文件夹里所有"多模态"论文，都是在修这件事。

还有一个容易忽略的点：前向 KL 在高斯族上的解，就是矩匹配——均值和协方差分别等于目标的均值和协方差（推导见 D5）。这解释了为什么 CEM 会去算精英样本的经验均值和经验协方差：它不是启发式，是前向 KL 在黎曼意义下的精确解。

0.3自由能恒等式（D1）

D1为什么"最小化代价"会变成一个"分布"变分路线 · 全篇地基
目标证明 minq Eq[J] + λ DKL(q‖ρ) 的唯一解是 p*(U) ∝ ρ(U) e−J(U)/λ，并把最小值写成配分函数的对数。
1

把 KL 展开，把三项并进一个对数里：

F(q) = Eq[J] + λ Eq[ log q − log ρ ] = λ Eq[ log q − log ρ + J/λ ]
2

定义未归一化目标 g(U) = ρ(U) e−J(U)/λ，配分函数 Z = ∫ g(U) dU。则 log g = log ρ − J/λ，代回：

F(q) = λ Eq[ log q − log g ] = λ Eq[ log q − log( g/Z ) ] − λ log Z = λ DKL( q ‖ p* ) − λ log Z

其中 p* = g/Z 已自动归一化。

3

因为 DKL ≥ 0 且等号仅在 q = p* 时成立，所以

minq F(q) = −λ log Z = −λ log ∫ ρ(U) e−J(U)/λ dU ,    argmin = p* .
4

读出两件事。(a) 目标分布是代价的指数倾斜。(b) 最小值 −λ log Z 就是 softmin：λ→0 时它趋近 minU J(U)，λ→∞ 时趋近常数（见 D4）。

这个式子在别的领域叫什么

Gibbs 变分原理 / Donsker–Varadhan 变分表示 / 变分自由能。物理里是 Helmholtz 自由能 F = U − TS（能量项 Eq[J]、熵项 −λDKL）；机器学习里是 ELBO 的负号版本；强化学习里是 max-entropy RL 的目标。同一个式子，四个名字。认出这一点，你看论文时就不会被术语挡住。

别误解"解是 p*"

D1 说的是在无约束的全体分布上最小化自由能，解才是 p*。实际算法把 q 限制在一个小族 Π（单高斯）里，这时解是 p* 在 Π 上的投影，而不是 p* 本身。λ→0 时投影会趋于把全部质量压到一个点上，那才是"优化"；λ 有限时你解的是一个软问题，最优点附近整片区域都有质量。这个区别是后面所有"为什么它不收敛到真最优"讨论的根源。

0.4重要性采样与有效样本数（D2）

D2为什么高维下采样会"看起来在跑，其实没信息"估计器 · 解释维度灾难
目标用提议 q 的样本估计 p* 下的期望，并给出一个可在线监控的退化指标。
1

重要性采样恒等式（对任意 q，只要 p* 绝对连续于 q）：

Ep*[ f(U) ] = Eq[ f(U) · p*(U)/q(U) ] .

记 wi = p*(Ui)/q(Ui)。因为 Z 未知，实际用自归一化版本：

ŵi = wi / ∑j wj ,    Ê[f] = ∑i ŵi f(Ui) .

偏差是 O(1/N)，对规划够用。

2

定义一个不需要知道 p* 归一化常数的退化指标——有效样本数：

ESS = 1 / ∑i ŵi2 ∈ [1, N] .

所有权重相等时 ESS = N；一个权重吃掉全部质量时 ESS = 1。它是"这 N 个样本里真正有用的有几个"。

3

Varq[ f · p*/q ] = Eq[ f2 (p*/q)2 ] − (Ep*[f])2 ,

维度诅咒的准确说法

不是"高维不能采样"，而是"提议与目标不匹配时，固定 N 的有效样本数随维度指数衰减"。反过来说，只要你把采样做在低维参数空间里（样条系数、动作块、基函数），或者让提议随目标一起移动（退火、热启动），问题就缓解了。A 文件夹里的 iCEM、低频采样、确定性采样，本质都在做这件事。

4

工程经验值：ESS/N > 0.1 一般还能用，低于 0.01 基本是在用一两个样本做决策。实践中应该把 ESS 打到日志里，和 N、λ、Σ 一起看——它比任何"收敛曲线"更能说明当前搜索是否真的在工作。

1.2路径积分路线（D3）

D3HJB 怎样变成"指数加权平均"路径积分 · 解释 MPPI 的物理来源
目标在受控扩散系统上，证明当控制代价与噪声匹配时，HJB 方程线性化，最优控制可以写成对采样扰动的指数加权平均。
1

系统与代价。受控扩散

dx = ( f(x) + G(x)u ) dt + B(x) dWt ,    cost = ∫0T ( ℓ(xt) + ½ u⊤R u ) dt + φ(xT) .

值函数 V(x,t) 满足 HJB：

−∂tV = minu { ℓ + ½u⊤Ru + ∇V⊤(f+Gu) + ½ tr(BB⊤∇2V) } .
2

对 u 求最小：Ru + G⊤∇V = 0 ⇒ u* = −R−1G⊤∇V。代回得到一个非线性 PDE，里面有一项 −½ ∇V⊤G R−1G⊤∇V。

3

关键的线性化技巧。若控制代价与噪声匹配，即存在常数 λ 使

G R−1 G⊤ = (1/λ) B B⊤ ,

则二次项 −½λ−1∇V⊤BB⊤∇V 与扩散二阶项 ½ tr(BB⊤∇2V) 可以合并。作变换 V = −λ log Ψ，则 ∇V = −λ∇Ψ/Ψ、∇2V = −λ(∇2Ψ/Ψ − ∇Ψ∇Ψ⊤/Ψ2)，代回后二次项精确抵消，得到线性方程

−∂tΨ = f⊤∇Ψ + ½ tr(BB⊤∇2Ψ) − (ℓ/λ) Ψ .
4

线性抛物型方程由 Feynman–Kac 给出路径期望解：

Ψ(x,t) = E[ exp( −(1/λ)( ∫tT ℓ ds + φ ) ) | xt = x ] ,

期望取在无控制的扩散 dx = f dt + B dW 上。然后 u* = −R−1G⊤∇V = λR−1G⊤∇Ψ/Ψ，而对数导数 ∇Ψ/Ψ 通过沿噪声路径的分部积分，变成"轨迹代价的指数加权平均"。

5

离散化到 MPPI 的形式。取名义控制 ū，扰动 Wi ~ N(0,Σ)，候选 Ui = ū + Wi，则最优更新是

ūnew = ū + E[ W e−J(ū+W)/λ ] / E[ e−J(ū+W)/λ ] ,

这正是 MPPI 的更新式（有限样本时把期望换成样本均值）。于是 MPPI 不是启发式，它是路径积分控制在离散、高斯扰动下的实例。

这条来路的边界

D3 成立需要三个条件：(1) 控制代价是二次的且与噪声精确匹配（GR−1G⊤ = BB⊤/λ）；(2) 扩散是布朗运动（高斯白噪声）；(3) 期望在无穷多样本上取。真实机器人上这三条全都不严格成立：代价不是二次的、噪声不是高斯的、样本有限。所以 D3 给你的不是"MPPI 最优"，而是"MPPI 在一个理想化问题上的最优解长什么样"。理解这一点，你就不会把 MPPI 的失败归咎于实现，也不会相信论文里"最优"的字面意思。

1.3温度的极限：λ 到底控制什么（D4）

D4λ→0 与 λ→∞ 两端分别发生什么极限 · 调参的第一性依据
目标给出 p* ∝ ρe−J/λ 在两个极限下的行为，并导出"λ 应该取多大"的可操作判据。
1

λ→0：集中到全局最优。设 J 有唯一全局最小点 U*（在 ρ 支撑内），则对任意 ε>0，

p*( ‖U−U*‖ > ε ) → 0 ,    −λ log Z → minU J(U) .

这是 Laplace 方法。算法层面的含义：λ 很小时 softmax 接近 one-hot，只有最优附近的少数样本有权重，ESS 崩到 1–2（回看 D2）。你等于在用 argmin 做决策，但付出了采样 N 个样本的代价。

2

λ→∞：退化成先验。e−J/λ → 1，于是 p* → ρ。若 ρ 是均匀分布，就是纯随机采样，完全没有优化；ESS = N。你花的算力全部浪费在"均匀探索"上。

3

可操作的判据。λ 应该与"样本间代价的典型差距"同量级。定义这一轮的代价标准差 sJ = stdi(Ji)，一个稳健的初值是

λ ≈ sJ / c ,    c ∈ [1, 5] ,

并在线检查 ESS/N：太大就减小 λ 或增大 Σ，太小就反向调。注意这个判据每轮都可能变（代价尺度随任务阶段变化），所以固定 λ 的实现在长时任务上经常时好时坏。

4

一个必须记住的耦合。在二次代价 + 高斯提议下，更新只依赖比值 Σ/λ（D9 严格证明）。这意味着"把噪声调大"和"把温度调低"在均值轨迹上是同一个旋钮。但它们不等价：Σ 还决定采样体积和 χ2，从而决定 ESS。所以实践中不能只调一个，必须看 ESS 一起调。

T1 的结论浓缩成一行

你优化的从来不是 min J，而是 minq∈Π Eq[J] + λDKL(q‖ρ)。λ 是这个问题的"软化程度"，Π 是你的表达能力，ρ 是你的先验。三者共同决定你实际解出什么。任何只谈 J 的"最优性"讨论都是不完整的。

T2 · 更新引擎主式落到地面：四个具体实例

现在到了整个知识树最该亲手推一遍的地方。主式里的"投影"是一个抽象的 argmin，这一层把它解出来。解出来之后你会发现：MPPI、CEM、Biased-MPPI、SVG-MPPI、Tsallis 之间真正的差别只有两个——用哪个散度、族 Π 有多大。

2.1投影到高斯族：矩匹配（D5）

D5前向 KL 在高斯族上的精确解就是矩匹配引擎核心 · MPPI 与 CEM 的共同祖先
目标解出 minμ,Σ DKL( p* ‖ N(μ,Σ) )，证明最优解是 μ = Ep*[U]、Σ = Covp*[U]。
1

把 KL 里对 q 无关的项丢掉。设 q = N(μ,Σ)：

DKL(p*‖q) = Ep*[ log p* ] − Ep*[ log N(U;μ,Σ) ] .

第一项与 μ,Σ 无关。所以最小化等价于最大化 Ep*[log N(U;μ,Σ)]——即加权最大似然。

2

代入高斯对数密度 log N = −½(U−μ)⊤Σ−1(U−μ) − ½log|Σ| + const，对 μ 求导并令零：

0 = Σ−1 Ep*[ U − μ ] ⇒ μ* = Ep*[U] .
3

对 P = Σ−1 求导：∇P log|P| = P−1 = Σ，二次型给 −½(U−μ)(U−μ)⊤，于是

0 = ½ Σ − ½ Ep*[ (U−μ)(U−μ)⊤ ] ⇒ Σ* = Covp*[U] .
4

这就是全部。前向 KL 到高斯族 = 匹配一二阶矩。没有别的。CEM 之所以去算精英样本的 mean/var，不是因为它是个"合理的启发式"，而是因为它是前向 KL 在样本近似下的精确解。

5

样本版本。只有样本时，用自归一化权重 ŵi 近似 p*：

μ̂ = ∑i ŵiUi ,    Σ̂ = ∑i ŵi(Ui−μ̂)(Ui−μ̂)⊤ .

如果样本不张满维度，Σ̂ 会奇异。实践中的两种做法：固定 Σ（MPPI）或加正则/收缩（CEM 的 Σ+εI）。这个选择直接引出下面两种方法的根本分歧。

一个常被忽略的推论

D5 说明：只要用前向 KL + 高斯族，更新就必然是"加权矩匹配"。如果你的方法既不是加权均值也不是加权协方差，那它一定用了别的散度（反向 KL、Tsallis、OT）或别的族（混合、粒子）。这条判据能让你在读新论文时一秒钟定位它在干什么。

2.2MPPI：固定协方差，只动均值（D6）

D6MPPI 更新式 = 平滑目标上的一次梯度步最重要的单个推导 · 同时解释"无导数"与"退火"
目标从"前向 KL + 固定 Σ"出发，推出 ū+ = ū + ∑i wiWi，并证明它等于 ū + Σ∇ū log g(ū)，其中 g = p* ∗ N(0,Σ) 是平滑后的目标。
1

设定。族限制为"均值可变、协方差固定"的高斯：qm = N(ūm, Σ)。用 qm 采样：Ui = ūm + Wi，Wi ~ N(0,Σ)，然后 rollout 得 Ji = J(Ui)。

2

权重。按主式，wi ∝ ρ(Ui)e−Ji/λ/qm(Ui)。在取 ρ = qm（用当前提议当先验，MPPI 的默认做法）时，权重简化成

wi = e−Ji/λ / ∑j e−Jj/λ .
这一步最容易搞错

如果你额外引入了一个与 qm 不同的基准 ρ₀ = N(ū0, Σ)（比如上一轮的名义解，或一个外部控制器给出的参考），那么权重里会多出一项对数密度比。高斯情况下它是线性的（D12 给完整形式），会造成一个额外的控制代价项。很多实现里"MPPI 有神秘偏差"，源头就在这里：把 ρ 写成了别的分布却用简化权重。

3

矩匹配。由 D5，μnew = ∑i wiUi。把它改写成"相对当前中心的增量"：

ū+ − ū = ∑i wi (Ui − ū) = ∑i wi Wi .

这就是 MPPI 更新式。到这里，它还是"矩匹配"的一个特例，看不出梯度。

4

关键等价。定义平滑目标

g(μ) = ∫ p̃*(U) N(U; μ, Σ) dU = EW ∼ N(0,Σ)[ p̃*(μ+W) ] ,    p̃*(U) := e−J(U)/λ .

（g 就是 p̃* 与高斯核的卷积，也等于 p̃* 在"加噪观测模型 y = U + ε"下的边缘密度。）记号提醒：这里的 p̃* 是固定的代价诱导密度；第 2 步取 ρ = qm 只是让权重化简为 e−J/λ，而 qm(U)e−J(U)/λ = N(U;ū,Σ)e−J/λ 恰好就是 p̃* 在当前中心处的核倾斜分布，两种读法给出同一个加权均值。对它取对数梯度，交换积分与求导：

∇μ log g(μ) = (1/g) ∫ p*(U) ∇μN(U;μ,Σ) dU .

用 ∇μN(U;μ,Σ) = Σ−1(U−μ)N(U;μ,Σ) 代入，得

∇μ log g(μ) = Σ−1 ( EU~p*(·)N(·;μ,Σ)/g[U] − μ ) .

括号里那个期望，按定义就是"在给定中心 μ、用核 N(0,Σ) 采样后按 p* 重加权的均值"——正是 ∑iwiUi 的总体版本。于是

ū+ = ū + Σ ∇ū log g(ū) MPPI 更新 = 在平滑目标上的预条件梯度上升，预条件矩阵就是采样协方差 Σ
5

三种读法，都对。

视角同一个式子的含义
变分前向 KL 投影到"固定 Σ 的高斯族"，解是矩匹配
优化对平滑目标 log g 做一次自然梯度步；Σ 是预条件
随机搜索零阶梯度估计：只用了 J 的值，却在估计 ∇log g

第三种读法解决了初学者最常问的那个问题：仿真器不可导，为什么还能"沿梯度方向"走？答案是——它从来没有对 J 求导。它对 平滑后的 log g 求导，而那个导数恰好可以写成"样本偏差的加权平均"，只需要代价的值。

由此一次性解释三件事

① 为什么 Σ 决定搜索半径：Σ 同时是采样核和预条件，核越宽平滑越强、单步跨度越大。
② 为什么"缩小方差"有时有用、有时有害：Σ→0 时 g → p*，你在优化真实目标，但梯度估计的方差按 Σ−1 放大。
③ 为什么退火有效：先用大 Σ 在平滑地形上走到正确的盆地，再缩小 Σ 精修（T3）。不是因为"退火总能找到全局最优"——它只是把"盆地选择"和"局部精修"两个子问题分开处理。

对照实现（MPPI 的三种常见写法）

① 噪声式：ū+ = ū + ∑wiWi　② 样本式：ū+ = ∑wiUi　③ 含基准漂移式：ū+ = ∑wiUi + Σ·(基准偏移项)。三者在 ρ=qm 时等价；一旦 ρ ≠ qm，只有 ③ 是对的。读到论文里"我们加了控制代价项"时，九成是在补这个差分。

2.3CEM：让协方差也动

CEM 是把 D5 里的 Σ̂ 真的用起来。它不预先指定协方差，而是每轮从精英样本估计：

精英集 ℰ = { i : Ji ≤ J(⌈ρN⌉) } ,    ū+ = mean(ℰ) ,   Σ+ = cov(ℰ) + εI . ρ 是精英比例（典型 0.05–0.2）

把它放到主式的框架里看，CEM 就是把光滑的指数权重换成了硬 0-1 截断：

wiCEM = 1[ Ji ≤ 阈值 ] ,   对比   wiMPPI ∝ exp(−Ji/λ) .
CEM 的特点

协方差自适应 ⇒ 自动从"宽搜索"过渡到"窄精修"，不需要手工调度；但样本少时 Σ̂ 噪声大、容易塌陷。精英比例 ρ 是它的温度旋钮。

MPPI 的特点

协方差固定 ⇒ 行为可预测，但搜索尺度全靠人调 Σ 和 λ；好处是权重光滑，梯度估计方差可控（这正是 D6 的预条件结构）。

两者其实是同一个极限关系

把 D8 的 Sinkhorn 传输写成 Π ∝ exp(−C/ε)，令 ε→0 就退化成"硬分配"，也就是 CEM 的精英截断。反过来，ε 有限时就是 soft-CEM / OT 版。所以 MPPI 与 CEM 不是对手，是温度的两端：MPPI 软、CEM 硬，中间是一整个连续谱。看论文时判断它在谱上的位置，就看它的权重函数是光滑的还是截断的。

2.4其他权重：Tsallis、风险、导引

权重函数是主式里最便宜的可改项——不改族、不改散度，只改"代价如何变成质量"。三种常见改动：

权重形式公式改的是什么代价
Tsallis / q-指数
L32		 w ∝ [1 − (r−1)J/λ̃]+1/(r−1) 重尾：小 r 时高代价样本仍有非零权重 r→1 回到 Gibbs；r<1 增加探索但减慢收敛

T3 · 搜索地形为什么同一算法有时神有时废

这一层是采样 MPC 最有洞察力、也最少被系统讲清楚的部分。核心问题是：MPPI 在"哪个函数"上做梯度上升？D6 已经给出答案——log g，即平滑后的目标。那么"平滑"这个动作到底改变了什么，就是全部关键。

3.1平滑、得分与"看不见的梯度"

把 D6 的结论放在中心位置：

∇y log pΣ(y) = Σ−1( Ep*(·|y)[U] − y ) ,    pΣ = p* ∗ N(0,Σ) . 平滑密度 pΣ 的得分 = "后验均值减去当前点"，再乘预条件

这个式子的三个直接推论，构成了整个 T3 的骨架：

推论含义
Σ 越大，地形越平滑pΣ 的峰更少、更宽。多峰 p* 在大 Σ 下可能合并成一个峰 ⇒ 大核能"跨过"局部极小。
Σ 越大，峰的位置越偏平滑会把峰往质量大的方向拉。尖锐不对称的峰（接触、碰撞）在大核下会明显偏移 ⇒ 大核找到的解不是原目标的解。
Σ→0，回到真实地形此时 g→p*，但得分中的 Σ−1 爆炸 ⇒ 方差失控。这是 D9 的定量版本。
"覆盖 vs 精修"不是玄学，是同一个式子里的两项

大核：平整地形（好盆地选择）+ 峰值偏移（解不准）。小核：地形崎岖（易困局部）+ 位置准确。任何固定的 Σ 都只能取一个折中。退火 = 让 Σ 随时间从大到小，依次拿到两者的好处。DIAL-MPC 的全部理论创新，就是把这件事从"工程技巧"提升为"有明确数学刻画的过程"。

3.2退火的两种尺度（DIAL-MPC 的核心）

D7退火为什么能同时得到覆盖与精修DIAL · 噪声日程的数学来源
目标把"大核覆盖、小核精修"写成一列平滑密度 pn，并说明它与扩散模型的关系。
1

定义一列平滑密度。设原始目标 p0 ∝ ρe−J/λ。定义

pn = p0 ∗ N(0, Σn) ,    ΣM ≻ ΣM−1 ≻ … ≻ Σ1 ≻ 0 .

每层用对应的核采样、按 D6 更新中心，得到中心序列 ūM → ūM−1 → … → ū1。

2

每层做什么。第 n 层执行 ūn+ = ūn + Σn∇log pn(ūn)。因为 pn 比 p0 平滑，这个梯度步跨得远、不容易被尖峰卡住；又因为 Σn 逐层变小，步长逐层收敛。

3

与扩散的关系。取前向加噪过程 zn = ᾱnz0 + √(1−ᾱn)ε，则边缘 pn 恰好是 p0 与高斯的卷积（D8）。所以"退火"就是"反向扩散"：从最平滑的边缘开始，逐层去噪回到 p0。DIAL-MPC 的理论主张正是"采样 MPC ≈ 单步去噪的序列"，而每一步都只是 D6 的加权均值。

4

两种退火尺度要分开。DIAL 用了两个独立因子：

轨迹级（层间）：det Σ(n) ∝ exp[ −(M−n)β1d / M ] ,    动作级（时域内）：det Σh(n) ∝ exp[ −(H−1−h)β2du / (H−1) ] .

前者让整段轨迹随层数收敛；后者让远端动作获得更大扰动、近端动作获得更小扰动。直觉：近端动作马上要执行，必须精确；远端动作还有多轮重规划机会，可以粗一些。这个设计在长时域、高频率执行的任务上收益明显。

5

一句诚实的边界。退火不保证找到全局最优。它保证的是"每层都在解一个更平滑的问题"，而在某些任务族（见 D7 的局限）里，平滑确实能把多峰合并成单峰，从而把盆地选择变成确定的。这需要 p0 的峰间距小于核宽——这是一个可以用数据检查的条件，而不是"退火总是有用"的信仰。

退火不解决的事

如果目标有两个相距很远、代价几乎相同的模式（比如左右两种抓取），且核宽远小于间距，那么退火只会收敛到"初始中心所在的那个盆地"。此时无论怎么调 β，都会漏掉另一半。这种情况需要 T4 的机制（多起点、粒子排斥、传输），退火无能为力。

3.3扩散视角：得分从哪来（D8）

D8去噪后验与得分估计连接 D-MPC / DIAL / MBD / Diffuser
目标从"加噪观测"模型出发，导出 ∇ylog pn(y) 的可用估计，说明它为何能只用 J 的值算出。
1

加噪模型。设 y = z0 + σ ε，ε~N(0,I)，z0 ~ p0。则 pσ(y) = ∫ p0(z)N(y;z,σ2I) dz。

2

后验。对 z0 配平方：p(z0|y) ∝ p0(z0)exp(−‖y−z0‖2/2σ2)，于是

p(z0|y) = p0(z0) e−J(z0)/λ e−‖y−z0‖2/2σ2 / Z(y) .

这就是"向低代价倾斜 + 向观测点靠拢"的联合后验。

3

得分（Tweedie 公式）。对 y 求导：

∇y log pσ(y) = (1/σ2)( E[z0|y] − y ) = −(1/σ) E[ε|y] .

两个等价写法：一个是"后验均值减当前点"，另一个是"预测噪声的期望"。它们分别对应两种实现：rollout 采样估计后验均值（DIAL/MBD 路线），或训练网络预测噪声（D-MPC/Diffuser 路线）。

4

这一节的最大收获

T4 · 多模态均值陷阱与六种出路

这一层存在的理由，可以一句话说完：前向 KL 是求平均的，而平均会毁掉模式。T2 的 D5 已经证明 MPPI 的更新是矩匹配——目标有两个峰时，单高斯的矩匹配解是"两峰之间的一个宽高斯"。它的均值落在谷底，而谷底是高代价的。这不是数值误差，是那个数学问题的正确解。

4.1陷阱的精确算例（D10）

D10双峰目标下，前向 KL 的最优解精确落在谷底精确可算 · 说明陷阱是固定点而非暂态
目标用一个完全可解析的例子，算出陷阱的位置、宽度，并证明它是 MPPI 迭代的不动点——也就是说，迭代不会自己逃出来。
1

设定一个双峰目标。令

p*(U) = ½ N(−a, s2) + ½ N(+a, s2) ,    a > 0 , s > 0 .

前向 KL 到单高斯（D5）。矩匹配给出

解是 N(0, a2+s2)：中心在正中间，方差比任一模态都大得多。

3

为什么它是迭代的不动点。从中心 ū = 0 采样，Wi ~ N(0,Σ)。因为目标和采样核都关于 0 对称，代价 J 也对称，所以权重满足 w(W) = w(−W)。于是

ū+ = 0 + ∑i wiWi ≈ 0 .

更新把中心留在了原地。再迭代一万次也还是 0。这就是"陷阱"二字的准确含义：它是一个稳定不动点，不是一步走错。

4

扰动分析。把一轮更新写成映射 ū+ = F(ū)。由于目标和采样核都关于 0 对称，F 是奇函数且 F(0) = 0。在 0 附近的线性化给出 F(δ) ≈ κδ，其增益 κ = F′(0) 完全由两侧权重的差决定：

κ = EW[ W · w′(W) ] / EW[ w(W) ] ,    w(W) = e−J(ū+W)/λ ,

在对称双井下 |κ| ≤ 1（这是"先取对数再归一化"的必然结果：加权均值不会把中心推过任一模态的中心）。于是 0 是吸引不动点——偏差只会被缩小，不会被放大。只有初始偏差大到足以让一侧样本在数量上压倒另一侧（即线性化失效）时才会逃出，这解释了"有时能跑、有时卡死"：取决于初始化，而不是迭代次数。

5

若用 CEM（协方差也更新）会怎样。精英样本来自两侧，经验方差继续膨胀，下一步采样更宽，两侧仍然均衡——同样不动。所以"换成 CEM"不是解法。

这个例子的三条教训

① 陷阱是前向 KL 的正确解，改实现没用，必须改散度或改族。② 对称性让它是稳定不动点，所以"多迭代几轮"无效。③ 它可以通过初始位置、噪声尺度、或显式多起点来绕过——这三条对应下面六种出路的本质。

4.3最优传输：分配而不是平均（D11）

D11Sinkhorn 迭代为什么能保住模式OT-MPC / MPOT 的数学内核
目标写出熵正则 OT 的问题、导出 Sinkhorn 的交替归一化，并说明它在采样控制里究竟替代了主式的哪一步。
1

问题。有 N 个样本（质量 ai）要"搬到"目标侧的 M 个位置（质量 bj，比如 N 个就对应 N 个目标点），搬运代价 Cij（欧氏距离的平方，或用代价 J）：

Π* = argminΠ ∈ 𝒞(a,b) ⟨C, Π⟩ − ε H(Π) ,    𝒞 = { Π ≥ 0 : Π1 = a , Π⊤1 = b } .

约束是"行和 = 供给、列和 = 需求"：每个样本的质量必须全部送出去，每个目标必须被填满。

2

解的结构。对 Π 求导（含行列约束的拉格朗日乘子 f, g）：

Πij = ui Kij vj ,    Kij = exp(−Cij/ε) ,    ui = efi/ε, vj = egj/ε .

即"一个固定的核矩阵 K 加两个对角缩放"。

3

Sinkhorn 迭代。交替满足两个约束（每次都是闭式）：

u ← a ⊘ (K v) ,    v ← b ⊘ (K⊤u) ,

重复到收敛（线性收敛，通常几十次就够）。这在实现上就是两次矩阵乘 + 逐元素除，非常便宜。

4

为什么它能保住模式。关键在"Π 是一个分配矩阵"。更新后的每个位置是

zi+ = ∑j (Πij/ai) · (目标点 j) ,

它是"把质量按最优方案搬到附近目标点后的位置"——质量不会被跨峡谷搬运，因为那样搬运代价太大。于是两簇样本各自朝自己那侧的峰移动，而不是合并到中间。ε→0 时退化成硬分配（类 CEM）；ε→∞ 时退化成均匀平均（回到 MPPI 的陷阱）。所以 ε 是"平均↔分配"的连续旋钮。

5

它替代了主式的哪一步。不是替代采样，也不是替代打分，而是替代"投影"：把"投影到单高斯（求矩）"换成"投影到传输计划（保质量搬运）"。族 Π 实际上从"一个高斯"变成了"一组保持分离的粒子"。这就是为什么 OT-MPC 能在不做聚类的情况下保住多条轨迹。

实现提醒

OT 需要一个目标侧的分布。实践中常见两种取法：把当前样本自身作为目标（自传输，等价于"只重排不改位置"），或把上一轮/先验样本作为目标。两者的语义完全不同，读论文时要看清 b 是什么。另外 C 用欧氏距离还是用 J 的差，决定了传输是"几何"还是"代价"驱动的。

最关键的一条设计原则

把"先验做什么"和"任务要什么"在结构上分开。D-MPC 的做法是显式分解 p(X,U|c) = pdyn(X|U,c)·ρθ(U|c)，任务代价只在最后的选择里进入：先由数据先验提候选，再由 R(X,U) 打分。这与 DIAL 的"代价进入每一轮 score"形成对比。前者换任务不改提议，后者换任务立刻改变搜索目标。

这个差别不是风格问题：先验来自数据、而任务来自人时，分离让"新任务"不需要新数据；先验很弱、但仿真可靠时，让代价深度参与能避免先验把搜索锁死。判断一篇论文属于哪类，看它的 J 出现在哪个位置就够了。

6.2先验错配：有效搜索体积的坍缩

一个不严格但很有用的量化直觉。设真实低代价集是 Ω*，先验 ρ 的质量集中在 Ωρ。则

P( 至少一个样本落在 Ω* ) ≈ 1 − (1 − ρ(Ω*))N ,    ρ(Ω*) = ∫Ω* ρ dU .

要让这个概率超过 1−δ，需要 N ≳ log(1/δ)/ρ(Ω*)。如果先验把 Ω* 的概率压到 10−6，你就需要百万级样本——这正是"离线学到的先验在新场景失效"的定量形态。相反，退火之所以有效，本质是让有效先验（大核卷积后的 pΣ）在早期覆盖更宽，把 ρ(Ω*) 人为抬高。

一个容易忽略的推论

先验和温度是竞争关系，不是独立旋钮。λ 很小而 ρ 很尖时，实际搜索体积由 ρ 决定，调 λ 几乎无效；λ 很大时 ρ 的影响被抹平，但你也失去了先验带来的方向性。调参时先看哪个在起主导作用，别同时拧两个。

6.3模型误差如何进入：它不只是"仿真不准"

采样 MPC 里模型的作用与梯度法不同：它不提供梯度，只提供候选轨迹的代价。所以模型误差的传导方式是——

Jmodel(U) = Jtrue(U) + ε(U) ,    于是   p*model ∝ p*true · e−ε(U)/λ .

这是一个乘性倾斜，和 D12 的形式一模一样。模型误差的作用等价于给目标分布加了一个与 λ 同阶的额外先验。两个直接后果：

  • λ 大（软目标）时模型误差的影响小，因为 ε/λ 小；但软目标本身解得不精确。
  • λ 小（硬目标）时模型误差被放大，算法会精确地优化一个错的代价——这比"优化得不准"更危险，因为它会自信地选错。
工程含义

模型越不准，越应该用较大的 λ 和较短的预测时域（减少误差累积），并用重规划频率来补偿。反过来，如果模型很准而 λ 取得很大，你是在浪费模型精度。这两者的匹配关系比任何单个超参都重要。

T7 · 闭环与系统把开环迭代塞进滚动决策

到目前为止我们解的都是一个时刻的开环问题：给定 xk，求 Uk* = (uk,…,uk+H−1)。真实系统要求的是闭环：执行 uk，观测新状态，重来。这一步看似只是"加个循环"，实际上引入了一整套新的理论问题，而且这些问题的答案大都不如宣传的那样强。

7.1滚动结构里真正发生的三件事

机制做什么为什么重要
首动作执行 只执行 uk，丢弃其余 把开环解变成反馈律；也是"为什么开环最优 ≠ 闭环最优"的来源
窗口前移 + 热启动 解 (uk+1,…,uk+H−1,·) 作为下一轮的初始中心 等价于给 ρ 一个强先验。好：省算力；坏：锁死在旧盆地（T6）
在线重规划 每 Δt 重解一次 补偿模型误差与扰动。Δt 越小误差累积越少，但算力需求越高
热启动是双刃剑

热启动让每一轮都在"上一轮最优解附近"搜索，这在任务不变时是巨大加速。但一旦出现突发的模式切换（障碍出现、接触丢失、目标改变），热启动会让搜索无法离开旧盆地——因为先验的质量几乎全在旧解上（T6.2 的坍缩）。工程解法：检测到"最优代价连续多轮不下降"或"ESS 异常低"时，临时重置中心或加宽 Σ。这类"退化检测"机制在论文里很少写，但在真机上几乎必需。

7.2稳定性与递归可行性：诚实的边界

这是最容易被论文标题误导的地方。需要分清三个层次：

性质经典 MPC 的条件采样 MPC 的现状
递归可行性 存在终端集 + 终端控制律，保证下轮问题可行 一般不成立。样本有限、无终端约束时，下一轮可能找不到可行解。常见补救：保留上一轮可行解作为兜底候选
闭环稳定性 终端代价 ≥ 值函数 + 可行性 ⇒ 单调下降 仅在极强假设下有结论（无限样本、精确优化、有终端项）。有限 N 时目标值甚至可能不单调
渐近最优性 — 有 λ→0、N→∞ 的极限结论；但 λ→0 与 ESS 塌陷冲突，实践里两者不能同时满足
该怎么读"provably stable"这类表述

先找三件事：(1) 有没有终端代价/终端集；(2) 优化器是否被假设为"精确求解"（采样 MPC 尤其做不到）；(3) 噪声是否被假设为零或高斯匹配。三者缺一，结论就退化成一个"在理想化模型上成立"的陈述。这不是说论文在骗人——理想化分析确实能揭示机制——但它不能直接搬到你的 G1 真机上。

一个更实用的替代目标：不要追求"证明稳定"，而是保证 (a) 每轮有可行解（兜底候选）、(b) 代价随重规划单调不升到某个界（监控曲线）、(c) 失败可检测（ESS/代价突变的告警）。

7.3算力预算：三个数的乘积

单轮耗时 ≈ N × H × ( 单步仿真成本 ) / 并行度 N 样本数 · H 预测步数 · 并行度由 GPU/多线程/多仿真器实例决定

这个乘积解释了 60 篇语料里大量工程工作的动机：

  • 降 N ⇒ 需要更好的先验（T6）或更强的更新（iCEM 的成功率外推、Smooth 采样）。
  • 降 H ⇒ 需要更短的窗口 + 更快的重规划，或样条/基函数参数化。
  • 提并行度 ⇒ GPU 批量仿真（MuJoCo MJX、Isaac）、MPPI-Generic 这类库。
  • 降单步成本 ⇒ 降阶模型、接触隐式的简化、点云/距离场的近似。
一个实用的取舍表
瓶颈优先动哪个
实时性不够先提并行（改仿真器），再考虑降 N；降 N 会直接损害搜索质量
解质量不够（次优/卡住）先修先验与退火，最后才加 N（N 的边际收益递减）
真机上抖动/不稳降低 λ 的时变性（平滑代价）、加重规划或加低通；不是加 N 能解决的
长时域任务失败缩短窗口 + 更多重规划，或用分层/事件级规划（外层离散选择）

! · 陷阱十个最常见的误解

  1. "MPPI 在用仿真器求梯度。" 不是。它在平滑目标上做梯度上升，只需代价的值（D6）。这也是为什么它能在不可导的接触模型上工作。

  2. "增大样本数 N 总能改善结果。" N 的收益受先验限制（T6.2）。如果先验把目标区域概率压得很低，加 N 的边际收益接近零，应该改先验或加退火。

  3. "CEM 和 MPPI 是两种不同算法。" 它们只差在权重函数（硬截断 vs 指数）和协方差是否自适应。在 OT 视角下是同一个温度旋钮的两端（§2.3）。

  4. "λ 调小就能更接近最优。" λ→0 会让 ESS 塌到 1–2（D4），你等于在用 argmin 但付了 N 次采样的代价；而且模型误差会被放大（T6.3）。

  5. "多迭代几轮就能跳出均值陷阱。" D10 说明它是稳定不动点。改迭代次数没用，必须改散度、族或换机制。

  6. "退火保证全局最优。" 只在"峰间距小于核宽"这类条件下成立（D7 的边界）。相距很远的等代价模式，退火无能为力。

  7. "加了控制代价项更保守、更安全。" 那一项可能只是 D12 的重要性修正。若基准 ρ 已等于采样分布 q，这一项应为零；错误地加两次会改变目标。

  8. "论文说 provably stable，所以能上真机。" 先查三个假设：终端项、精确优化、噪声匹配（T7.2）。采样 MPC 通常三条都不满足。

  9. "约束用 clip 处理就够了。" clip 会让边界外代价变平，搜索吸附到边界（D14）。非凸约束下"平均后投影"也不保证可行。

  10. "离线学到的先验可以直接换任务用。" 先验覆盖的是训练分布。换任务/换动力学时，先验与任务代价必须分离（T6.1），否则先验会把搜索锁死。
