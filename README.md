# SMPC Baseline

Sampling-based model predictive control research workspace: literature, research notes, interactive knowledge maps, and a local Hydrax baseline.

## Contents

- `papers/`: collected research papers and foundations material.
- `doc/`: literature map, research directions, paper reading reports, and download lists.
- `SMPC_Knowledge_Tree.html`: interactive knowledge tree.
- `src/hydrax/`: Hydrax source snapshot with local adaptations; see its README for setup and usage.
- `.agents/`: project research skills.
